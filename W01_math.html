單元概述

本章「數與式」是高中數學的起點，奠定整個數學學科的運算語言基礎。從認識各種數的集合關係，到熟練掌握根式與指數的化簡技巧，都是後續學習函數、方程式、不等式、對數、三角函數不可或缺的基石。


學習目標

  • 能分辨並說明實數系統中各數集的包含關係
  • 能利用數線表示實數，並計算絕對值
  • 能掌握實數的域（field）性質：加法與乘法的交換、結合、分配律
  • 能化簡各類根式，包含多重根號與分母有理化
  • 能靈活運用指數律（乘法、除法、次方、負指數、分數指數）

在課程脈絡中的位置

本章為第一冊第1章，是全高中數學的「語言建構期」。學完本章後，下一個連結單元是第2章：多項式（代入、因式定理），以及第3章：函數。根式與指數技巧在指數對數（第二冊）和極限與微分（高三數甲選修）中將大量應用。

  • 整數、分數、小數的四則運算

  • 指數的基本意義（\(2^3 = 8\)）

1. 實數的分類

1.1 有理數（Rational Numbers）與無理數（Irrational Numbers）

📖 定義：有理數

凡是可以表示成 p/q（其中 p、q 為整數，且 q ≠ 0）的數，稱為有理數。

  • 整數（含正整數、0、負整數）都是有理數，例：5 = 5/1
  • 有限小數與循環小數都是有理數，例：0.333... = 1/3
📖 定義：無理數

無法表示成兩個整數之比的實數，稱為無理數。其小數展開為無限不循環小數。

  • 常見無理數：\(\sqrt{2},\ \sqrt{3},\ \sqrt{5},\ \pi,\ e\)
  • 判斷：\(\sqrt{n}\) 中，若 n 不是完全平方數，則 \(\sqrt{n}\) 為無理數
⚠️ 常見錯誤 #1

以為 \(\pi\) 是有理數。 很多同學誤認 \(\pi \approx 22/7\)，這只是近似值，\(\pi\) 本身無法精確寫成整數比，為無理數。

例題 1-1
判斷下列各數屬於有理數還是無理數：
(a) \(\sqrt{16}\)　(b) \(\sqrt{7}\)　(c) \(0.\overline{142857}\)　(d) \(\sqrt{2}+\sqrt{8}\)
(a) \(\sqrt{16} = 4\)，為整數，故為有理數。
(b) 7 不是完全平方數，故 \(\sqrt{7}\) 為無理數。
(c) \(0.\overline{142857} = \frac{1}{7}\)，為有限比值，故為有理數（循環小數）。
(d) \(\sqrt{2}+\sqrt{8} = \sqrt{2}+2\sqrt{2} = 3\sqrt{2}\)。因 \(\sqrt{2}\) 為無理數，
    有理數 3 乘以無理數仍為無理數。
⚠️ 常見錯誤 #2：「兩無理數相加仍是無理數」── 不一定！

例：\((\sqrt{2}) + (-\sqrt{2}) = 0\)，結果為有理數。
又如：\((3+\sqrt{2}) + (1-\sqrt{2}) = 4\)，結果也為有理數。
兩無理數相加，結果可能是有理數！

1.2 實數系統的包含關係

實數 (ℝ) 的分類如下（以集合包含關係呈現）：

實數（ℝ）
  • 有理數（ℚ） 可表示為分數 p/q（p, q 為整數，q ≠ 0）；含有限小數與循環小數。例：\(-3,\ 0,\ \tfrac{1}{3},\ 0.\overline{6}\)
    • 整數（ℤ） 例：\(-3,\ 0,\ 2,\ 100\)
      • 自然數（ℕ，含 0）：\(0,\ 1,\ 2,\ 3,\ \ldots\)
  • 無理數 無法表示為分數；無限不循環小數。例：\(\sqrt{2},\ \sqrt{3},\ \pi,\ e\)
💡 記憶口訣

「自整有實」── 自然數 ⊂ 整數 ⊂ 有理數 ⊂ 實數
無理數與有理數合在一起才等於實數：ℝ = ℚ ∪ (ℝ∖ℚ)

2. 數線與絕對值

2.1 數線（Number Line）

一條無限延伸的直線，選定原點 O（對應 0）、正方向（向右）、單位長度後，每個實數都對應數線上唯一的點，反之亦然。這種對應稱為實數與數線的一一對應。

數線上 \(\sqrt{2} \approx 1.414\) 的位置介於 1 和 2 之間（橘點標示）。

2.2 絕對值（Absolute Value）

📖 定義：絕對值

實數 \(a\) 的絕對值 \(|a|\) 定義為：

|a| = a，若 a ≥ 0
|a| = -a，若 a < 0

幾何意義：\(|a|\) 是數線上點 \(a\) 到原點 O 的距離；\(|a-b|\) 是點 \(a\) 到點 \(b\) 的距離。

2.3 絕對值的性質

公式：絕對值基本性質
① |a| ≥ 0，等號成立 ⟺ a = 0
② |a| = |-a|
③ |ab| = |a||b|
④ |a/b| = |a|/|b|（b ≠ 0）
⑤ |a+b| ≤ |a|+|b| ← 三角不等式（Triangle Inequality）
⑥ √(a²) = |a|（注意！不等於 a）
⚠️ 常見錯誤 #3：\(\sqrt{a^2} = a\)？

大多數同學直覺認為 \(\sqrt{a^2} = a\)，但這只在 a ≥ 0 時成立！
正確寫法：\(\sqrt{a^2} = |a|\)
例：\(\sqrt{(-3)^2} = \sqrt{9} = 3 = |-3|\)，而非 -3。

例題 2-1
已知 \(a < 0\)，化簡 \(\sqrt{a^2 - 2a + 1}\)。
辨識完全平方式：\(a^2 - 2a + 1 = (a-1)^2\)
開根號：\(\sqrt{(a-1)^2} = |a-1|\)
判斷符號：因 \(a < 0\)，所以 \(a - 1 < -1 < 0\)，故 \(a - 1 < 0\)
代入定義：\(|a-1| = -(a-1) = 1-a\)
答：\(\sqrt{a^2-2a+1} = 1-a\)
例題 2-2
解方程式 \(|2x - 3| = 5\)。
絕對值方程 \(|A| = k\)（k > 0）等價於 \(A = k\) 或 \(A = -k\)
情況一：\(2x-3 = 5 \Rightarrow 2x = 8 \Rightarrow x = 4\)
情況二：\(2x-3 = -5 \Rightarrow 2x = -2 \Rightarrow x = -1\)
答：\(x = 4\) 或 \(x = -1\)

3. 實數的運算性質

實數集合 ℝ 在加法與乘法下構成一個域（Field），具有以下基本性質：

公式：實數的基本運算性質（加法）
交換律：a + b = b + a
結合律：(a + b) + c = a + (b + c)
加法單位元：a + 0 = a
加法反元素：a + (-a) = 0
公式：實數的基本運算性質（乘法）
交換律：a × b = b × a
結合律：(a × b) × c = a × (b × c)
乘法單位元：a × 1 = a
乘法反元素：a × (1/a) = 1（a ≠ 0）
分配律：a × (b + c) = a×b + a×c
💡 常用推論（加法與乘法連結）
  • \(a \times 0 = 0\)（任何數乘以零等於零）
  • \((-a) \times b = -(ab)\)；\((-a)(-b) = ab\)
  • 若 \(ab = 0\)，則 \(a = 0\) 或 \(b = 0\)（零積性質，解方程式核心！）
🔗 連結提示：多項式因式分解

零積性質「\(ab=0 \Rightarrow a=0\) 或 \(b=0\)」是第2章解多項式方程的基礎。例如解 \(x^2-5x+6=0\) 需先分解為 \((x-2)(x-3)=0\)，再用零積性質求解。

4. 根式化簡

4.1 根式的基本性質

📖 定義：n 次方根

若 \(x^n = a\)，則稱 \(x\) 為 \(a\) 的 \(n\) 次方根，記作 \(\sqrt[n]{a}\)。

  • n 為偶數：\(a \geq 0\) 才有實數解，\(\sqrt[n]{a} \geq 0\)（取算術根，即正值）
  • n 為奇數：任意實數 a 均有唯一實數 n 次方根
  • 特別：\(\sqrt{a} = \sqrt[2]{a}\)，一般不標 2
公式：根式運算性質（a, b ≥ 0）
① √a · √b = √(ab)
② √a / √b = √(a/b)　（b ≠ 0）
③ (√a)² = a　（a ≥ 0）
④ √(a²) = |a|　（a 為任意實數）
⑤ ⁿ√(ᵐ√a) = ᵐⁿ√a　（多重根號化簡）
例題 4-1：根式化簡（提出完全平方因數）
化簡 \(\sqrt{72}\)。
質因數分解：\(72 = 8 \times 9 = 2^3 \times 3^2\)
分離完全平方因數：\(\sqrt{72} = \sqrt{36 \times 2} = \sqrt{36}\cdot\sqrt{2}\)
化簡：\(= 6\sqrt{2}\)
答：\(\sqrt{72} = 6\sqrt{2}\)
例題 4-2：同類根式合併
化簡 \(3\sqrt{12} - 2\sqrt{27} + \sqrt{48}\)。
\(3\sqrt{12} = 3\sqrt{4\cdot 3} = 3 \times 2\sqrt{3} = 6\sqrt{3}\)
\(2\sqrt{27} = 2\sqrt{9\cdot 3} = 2 \times 3\sqrt{3} = 6\sqrt{3}\)
\(\sqrt{48} = \sqrt{16\cdot 3} = 4\sqrt{3}\)
合併：\(6\sqrt{3} - 6\sqrt{3} + 4\sqrt{3} = 4\sqrt{3}\)
答：\(4\sqrt{3}\)
例題 4-3：去除多重根號
化簡 \(\sqrt[3]{\sqrt{8}}\)。
轉換：\(\sqrt[3]{\sqrt{8}} = \sqrt[3]{8^{1/2}} = (8^{1/2})^{1/3} = 8^{1/6}\)
\(= \sqrt[6]{8} = \sqrt[6]{2^3} = 2^{3/6} = 2^{1/2} = \sqrt{2}\)
答：\(\sqrt{2}\)

4.2 分母有理化（Rationalization）

📖 定義：有理化

將分數的分母中的根號消除，轉化為有理數形式，稱為分母有理化（rationalization of the denominator）。

公式：有理化方法
類型一（單根號）： 1/√a = √a/a　（分子分母同乘 √a） 類型二（二項式）：使用共軛根式 1/(√a + √b) = (√a - √b)/((√a)²-(√b)²) = (√a - √b)/(a-b) 記憶：(√a+√b)(√a-√b) = a-b　← 平方差公式
例題 4-4：二項式有理化
化簡 \(\dfrac{3}{\sqrt{5}-\sqrt{2}}\)。
分子分母同乘共軛根式 \((\sqrt{5}+\sqrt{2})\)：
\(\dfrac{3}{\sqrt{5}-\sqrt{2}} \times \dfrac{\sqrt{5}+\sqrt{2}}{\sqrt{5}+\sqrt{2}}\)
分母：\((\sqrt{5})^2 - (\sqrt{2})^2 = 5 - 2 = 3\)
整理：\(\dfrac{3(\sqrt{5}+\sqrt{2})}{3} = \sqrt{5}+\sqrt{2}\)
答：\(\sqrt{5}+\sqrt{2}\)
例題 4-5：連續有理化（學測常考型）
化簡 \(\dfrac{1}{\sqrt{2}+1} + \dfrac{1}{\sqrt{3}+\sqrt{2}} + \dfrac{1}{\sqrt{4}+\sqrt{3}}\)。
每一項分別有理化（乘共軛）：
\(\dfrac{1}{\sqrt{2}+1} = \dfrac{\sqrt{2}-1}{(\sqrt{2}+1)(\sqrt{2}-1)} = \dfrac{\sqrt{2}-1}{2-1} = \sqrt{2}-1\)
\(\dfrac{1}{\sqrt{3}+\sqrt{2}} = \dfrac{\sqrt{3}-\sqrt{2}}{3-2} = \sqrt{3}-\sqrt{2}\)
\(\dfrac{1}{\sqrt{4}+\sqrt{3}} = \dfrac{\sqrt{4}-\sqrt{3}}{4-3} = 2-\sqrt{3}\)
相加（觀察疊消現象）：
\((\sqrt{2}-1) + (\sqrt{3}-\sqrt{2}) + (2-\sqrt{3})\)
\(= \sqrt{2} - 1 + \sqrt{3} - \sqrt{2} + 2 - \sqrt{3}\)
\(= (-1+2) + (\sqrt{2}-\sqrt{2}) + (\sqrt{3}-\sqrt{3}) = 1\)
答：1
規律：此類「連續有理化疊消」為學測高頻出題模式，連加後中間項皆消去，只留頭尾兩項。
⚠️ 常見錯誤 #4

有理化時忘記分子也要乘以共軛根式，只改了分母。
正確做法是分子分母同乘同一個共軛根式，才不改變分數值。

5. 指數運算基礎

📖 定義：整數指數

設 \(a \neq 0\)，n 為正整數：

  • \(a^n = a \times a \times \cdots \times a\)（n 個 a 相乘）
  • \(a^0 = 1\)
  • \(a^{-n} = \dfrac{1}{a^n}\)
📖 定義：分數指數

設 \(a > 0\)，m 為整數，n 為正整數：

a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ

特別：\(a^{1/n} = \sqrt[n]{a}\)，即分數指數與根式互通。

公式：指數律（Index Laws）— 核心必背
設 a > 0，b > 0，m、n 為有理數： ① aᵐ · aⁿ = aᵐ⁺ⁿ　（同底相乘，指數相加） ② aᵐ / aⁿ = aᵐ⁻ⁿ　（同底相除，指數相減） ③ (aᵐ)ⁿ = aᵐⁿ　　（次方的次方，指數相乘） ④ (ab)ⁿ = aⁿbⁿ　　（乘積的次方） ⑤ (a/b)ⁿ = aⁿ/bⁿ　（商的次方）
例題 5-1：指數律化簡
化簡 \(\dfrac{a^{3/2} \cdot a^{1/3}}{a^{5/6}}\)（\(a > 0\)）。
分子指數相加：\(3/2 + 1/3 = 9/6 + 2/6 = 11/6\)
同底相除：\(a^{11/6} \div a^{5/6} = a^{11/6 - 5/6} = a^{6/6} = a^1 = a\)
答：\(a\)
例題 5-2：化根式為指數，再化簡（學測常見）
化簡 \(\sqrt{a\sqrt{a}}\)（\(a > 0\)），以指數形式表示。
由內而外化為指數：\(\sqrt{a} = a^{1/2}\)
\(a\sqrt{a} = a \cdot a^{1/2} = a^{1+1/2} = a^{3/2}\)
\(\sqrt{a\sqrt{a}} = (a^{3/2})^{1/2} = a^{3/4}\)
答：\(a^{3/4}\)
例題 5-3：負指數與有理數指數
計算 \(8^{-2/3} + 16^{3/4}\)。
\(8^{-2/3} = (2^3)^{-2/3} = 2^{3 \times (-2/3)} = 2^{-2} = \dfrac{1}{4}\)
\(16^{3/4} = (2^4)^{3/4} = 2^{4 \times 3/4} = 2^3 = 8\)
相加：\(\dfrac{1}{4} + 8 = \dfrac{1}{4} + \dfrac{32}{4} = \dfrac{33}{4}\)
答：\(\dfrac{33}{4}\)
⚠️ 常見錯誤 #5：指數律的誤用
  • 錯：\(a^m + a^n = a^{m+n}\)（指數律只適用於乘法，不適用於加法！）
  • 對：\(a^m \times a^n = a^{m+n}\)
  • 錯：\((a+b)^2 = a^2 + b^2\)（正確應含 \(2ab\) 項）
💡 解題技巧：先轉換底數

遇到含多種數的指數運算，先把所有數轉換為最小的質數底數（通常是 2、3、5、7）再使用指數律，能大幅減少計算錯誤。
例：\(4^3 = (2^2)^3 = 2^6\)；\(27^{2/3} = (3^3)^{2/3} = 3^2 = 9\)。

重點整理

  • 實數系統：自然數 ⊂ 整數 ⊂ 有理數 ⊂ 實數；無理數 ∪ 有理數 = 實數（互斥且合完全）
  • 判斷 \(\sqrt{n}\) 是否為無理數：n 為完全平方數 → 有理數；否則 → 無理數
  • 兩無理數相加 / 相乘，結果不一定是無理數（需個別判斷）
  • \(|a|\) 定義：a ≥ 0 時等於 a；a < 0 時等於 −a；永遠非負
  • \(\sqrt{a^2} = |a|\)（非 a），是最高頻考點之一
  • 三角不等式：\(|a+b| \leq |a|+|b|\)，等號在 ab ≥ 0 時成立
  • 根式化簡步驟：① 質因數分解 → ② 提出完全平方因數 → ③ 有理化（若分母含根號）
  • 有理化：分母含 \(\sqrt{a}\) 乘以 \(\sqrt{a}\)；含 \(\sqrt{a}±\sqrt{b}\) 乘以共軛 \(\sqrt{a}∓\sqrt{b}\)
  • 分數指數：\(a^{m/n} = \sqrt[n]{a^m}\)；特別 \(a^{1/2} = \sqrt{a}\)
  • 指數律五條：同底乘（指數加）、同底除（指數減）、次方（指數乘）、乘積次方、商次方
  • 解題妙招：先將底數統一為最小質數，再應用指數律

練習題

💡 作答建議

請先獨立作答，完成後再展開解答確認。計算題請詳列解題步驟，養成學測作答習慣。

1
【分類判斷】下列各數中，哪些是有理數，哪些是無理數？
\(\sqrt{25},\quad \sqrt{6},\quad -\dfrac{7}{3},\quad 0.\overline{3},\quad \pi^0,\quad \sqrt[3]{8}\)
展開解答
  • \(\sqrt{25} = 5\) → 有理數（整數）
  • \(\sqrt{6}\)：6 非完全平方數 → 無理數
  • \(-\dfrac{7}{3}\)：整數比 → 有理數
  • \(0.\overline{3} = \dfrac{1}{3}\)：循環小數 → 有理數
  • \(\pi^0 = 1\)（任意非零數的 0 次方為 1）→ 有理數
  • \(\sqrt[3]{8} = 2\)（\(2^3=8\)）→ 有理數

有理數：\(\sqrt{25}, -\dfrac{7}{3}, 0.\overline{3}, \pi^0, \sqrt[3]{8}\)；無理數：\(\sqrt{6}\)

2
【絕對值化簡】已知 \(x < -2\)，化簡 \(|x+2| + |x-1|\)。
展開解答

因 \(x < -2\)，所以：

  • \(x + 2 < 0\)，故 \(|x+2| = -(x+2) = -x-2\)
  • \(x - 1 < -3 < 0\)，故 \(|x-1| = -(x-1) = -x+1\)

合計：\((-x-2) + (-x+1) = -2x - 1\)

答：\(-2x-1\)（因 x < −2，此值大於 3，為正值，合理）

3
【根式化簡】化簡 \(\sqrt{50} - \sqrt{18} + \sqrt{8}\)。
展開解答
  • \(\sqrt{50} = \sqrt{25 \cdot 2} = 5\sqrt{2}\)
  • \(\sqrt{18} = \sqrt{9 \cdot 2} = 3\sqrt{2}\)
  • \(\sqrt{8} = \sqrt{4 \cdot 2} = 2\sqrt{2}\)

合計：\(5\sqrt{2} - 3\sqrt{2} + 2\sqrt{2} = 4\sqrt{2}\)

答：\(4\sqrt{2}\)

4
【有理化】化簡 \(\dfrac{\sqrt{3}+1}{\sqrt{3}-1}\)。
展開解答

分子分母同乘共軛根式 \((\sqrt{3}+1)\)：

\(\dfrac{(\sqrt{3}+1)^2}{(\sqrt{3})^2-1^2} = \dfrac{3+2\sqrt{3}+1}{3-1} = \dfrac{4+2\sqrt{3}}{2} = 2+\sqrt{3}\)

答：\(2+\sqrt{3}\)

5
【指數運算】計算 \(27^{1/3} \times 4^{-1/2} + 9^{3/2} \div 3^2\)。
展開解答
  • \(27^{1/3} = (3^3)^{1/3} = 3\)
  • \(4^{-1/2} = (2^2)^{-1/2} = 2^{-1} = \dfrac{1}{2}\)
  • \(9^{3/2} = (3^2)^{3/2} = 3^3 = 27\)
  • \(3^2 = 9\)

計算：\(3 \times \dfrac{1}{2} + 27 \div 9 = \dfrac{3}{2} + 3 = \dfrac{3}{2} + \dfrac{6}{2} = \dfrac{9}{2}\)

答：\(\dfrac{9}{2}\)

6
【綜合計算】化簡 \(\sqrt[3]{\sqrt{64}}\)，以最簡形式表示。
展開解答

方法一（逐步化簡）：

\(\sqrt{64} = 8\)，故 \(\sqrt[3]{8} = \sqrt[3]{2^3} = 2\)

方法二（指數法驗算）：

\(\sqrt[3]{\sqrt{64}} = (64^{1/2})^{1/3} = 64^{1/6} = (2^6)^{1/6} = 2^1 = 2\)

答：\(2\)

7
【絕對值方程】求滿足 \(|3x+1| = |x-3|\) 的所有實數解。
展開解答

\(|A| = |B|\) 等價於 \(A = B\) 或 \(A = -B\)：

情況一：\(3x+1 = x-3\) → \(2x = -4\) → \(x = -2\)

情況二：\(3x+1 = -(x-3)\) → \(3x+1 = -x+3\) → \(4x = 2\) → \(x = \dfrac{1}{2}\)

答：\(x = -2\) 或 \(x = \dfrac{1}{2}\)

8
【學測模擬題】設 \(a = \sqrt{3}+\sqrt{2}\)，\(b = \sqrt{3}-\sqrt{2}\)，求 \(a^2+b^2\) 與 \(ab\) 的值，並判斷 \(a^2+b^2\) 為有理數還是無理數。
展開解答

求 ab：

\(ab = (\sqrt{3}+\sqrt{2})(\sqrt{3}-\sqrt{2}) = 3 - 2 = 1\)（平方差公式）


求 a+b：

\(a+b = (\sqrt{3}+\sqrt{2}) + (\sqrt{3}-\sqrt{2}) = 2\sqrt{3}\)


求 a²+b²：

\(a^2+b^2 = (a+b)^2 - 2ab = (2\sqrt{3})^2 - 2 \times 1 = 12 - 2 = 10\)


判斷：\(a^2+b^2 = 10\)，為整數，故為有理數。

（此題示範：兩無理數 a、b 的平方和可以是有理數！）
