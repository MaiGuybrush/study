✍️感性題 vs. 知性題：核心差異

🌱 國寫兩大類型，各佔 25 級分

國語文寫作能力測驗（國寫）由「知性題（論說性寫作）」與「感性題（抒情性寫作）」兩大題型組成，各佔 25 級分，合計 50 級分。W14 已練習過知性題著重的是「說理」——如何針對引導材料提出清晰的論點並加以論證；本週練習的感性題著重的則是「抒情」——如何從個人生命經驗出發，透過具體的畫面、物件與細節，傳達真摯而有層次的情感體悟。

兩者核心差異對照

比較項目知性題（論說性寫作）感性題（抒情性寫作）
測驗核心邏輯思辨、論證與批判能力情感體察、細節經營與感受轉化能力
取材依據引導材料（文字／圖表數據）＋客觀分析個人生命經驗、記憶片段、具體物件或場景
常見結構總—分—總／問題—分析—結論，段落間需有明確論證邏輯由具體畫面或物件切入，鋪陳細節與情感轉折，收束於體悟或轉念
語言風格精確、條理分明，避免情緒化用語講究意象經營、感官摹寫與情感節奏，可適度使用譬喻、轉化等修辭
最忌諱只重述材料、缺乏個人分析與明確論點空喊口號式的情緒詞彙（如反覆寫「我很感動」），卻沒有具體細節支撐
💡 一句話理解兩者差異

知性題要你「證明一個道理」，感性題要你「重現一段感受」——感性題的關鍵不在於情感有多濃烈，而在於能否用具體可感的細節，讓讀者「看見」你所經歷的那個當下。

🎯感性題評分四大規準

取材與情感真摯度

取材是否貼近題目要求、是否為考生自身真實可信的生命經驗；情感表達是否真誠自然，避免刻意誇大或套用陳腔濫調的感人情節。

意象經營與細節描寫

是否善用具體的感官細節（視覺、聽覺、觸覺等）與意象，將抽象情感轉化為可感的畫面，避免空泛地直接陳述情緒。

結構與情感層次

全文是否有清楚的情感發展脈絡（如：由平靜到波動、由困惑到體悟），段落安排能否呈現情感或思緒的轉折與遞進，而非平鋪直敘。

語言表達與文采

文句是否通順優美、用詞是否精準生動，修辭手法（譬喻、轉化、摹寫等）運用是否自然貼切，而非為修辭而修辭。

📝範例練習與寫作大綱示範

模擬題組

引導材料

每個人的生命中，或許都曾擁有一件看似平凡、卻在某個時刻忽然變得意義非凡的物件——它可能是一支用了多年的筆、一張泛黃的照片、一件舊衣服，或是家中某個角落的擺設。這些物件平時並不起眼，卻悄悄承載著一段時光、一份情感，或是一個已經改變的自己。

寫作要求

請以「那件小事物」為題，寫一篇文章，記敘一件對你別具意義的物件，並抒發你從中體會到的情感與感悟。文長不限，但須有完整的起、承、轉、合結構。

寫作大綱範例（供練習參考，非完整範文）

💡 「畫面切入—細節鋪陳—轉念體悟—收束呼應」結構示範
  • 起（具體畫面切入）：不從「我要寫一件對我很重要的東西」這類直述句開始，而是先描繪一個具體的當下畫面——例如：翻找抽屜時，指尖無意間碰到那支筆蓋已經磨損的鋼筆，勾起一段塵封的記憶
  • 承（細節鋪陳回憶）：倒敘描寫這件物件的來歷與當時的情境（如：那是祖父教自己寫第一個字時所用的筆），運用具體的感官細節（筆身的重量、墨水的氣味、握筆時的觸感）讓回憶重現，而非籠統帶過
  • 轉（轉念與體悟）：描寫物件與現在的自己產生的呼應或落差（如：祖父已經過世，但握筆寫字的習慣卻成為自己與他之間仍然延續的連結），情感由平靜的懷念轉向更深一層的體悟
  • 合（收束呼應）：回到現在的時空，總結這件小事物對自己的意義——它提醒著自己某種被珍視的價值或情感的延續，並可與篇首畫面首尾呼應，讓文章結構完整
🔗 可運用的意象經營技巧
  • 感官摹寫：不只寫「這支筆很舊」，而是具體寫出「筆蓋邊緣已磨得發亮，握在掌心還留著淡淡的木頭氣味」
  • 今昔對照：透過物件連結過去與現在兩個時空，凸顯時間流逝與情感沉澱的層次感
  • 以物寫情、以小見大：讓一件微小的物件承載較大的情感命題（如親情、成長、失去與延續），避免情感直接空泛地說出口

⚠️感性題常見失分原因

  • 情感表述空泛，只反覆寫「我很感動」「我很難過」等抽象詞彙，卻沒有具體細節支撐，讀者難以感同身受
  • 取材不夠具體真實，內容流於套用坊間常見的「感人故事」模板，情感顯得刻意而不自然
  • 結構鬆散，全文平鋪直敘、缺乏情感或思緒的轉折層次，讀來像流水帳而非有機的篇章
  • 修辭堆砌過度，為了展現文采而使用大量華麗辭藻，反而使情感顯得矯情、失真
  • 離題或偏題，未緊扣題目要求的具體寫作對象（如題目要求寫「物件」，卻整篇只泛泛談論抽象的親情觀念）

📜古文語文知識整理｜通同字／古今字

🏆 古文30篇已全數完成（30/30），本週進行語文知識總複習

以下五大類別的例句，皆直接摘引自 W01–W12 已學過的古文30篇原文（公版古典文獻，全文引用），依語文知識類別重新歸納整理，是學測國文選擇題「字詞辨析」「語文常識」題型的固定必考範疇。

通同字（通假字）指古文中借用讀音相同或相近的字來代替本字；古今字則是同一詞義因時代演變而先後使用不同字形。以下例句均取自已學篇目原句：

原句（全文引用）出處通／本字釋義
「行李之往來，共其乏困」燭之武退秦師共＝供供給、供應
「秦伯說，與鄭人盟」燭之武退秦師說＝悅高興、喜悅
「便要還家，設酒殺雞作食」桃花源記要＝邀邀請
「或師焉，或不焉」師說不＝否不、否定（此處指不從師學習）
「爾來二十有一年矣」出師表有＝又表示整數之外再加零數
「必能裨補闕漏，有所廣益」出師表闕＝缺缺失、疏漏
「蚤繅而緒，蚤織而縷」柳宗元〈種樹郭橐駝傳〉（非古文30篇，僅舉例）蚤＝早及早、盡早
「所守或匪親，化為狼與豺」句型中「匪」字通例｜「淇則有岸，隰則有泮」類推補充語文知識延伸補充匪＝非不是（常見通假字，供舉一反三）

上表最後兩列為延伸補充之通假字觀念舉隅，非出自古文30篇原文，供辨析同類語文現象參考。

🔤一字多義

以下虛實詞是學測文言文閱讀最常考的「一字多義」重點，每個字皆列出至少兩個出自古文30篇原文、意義不同的例句（全文引用單句）：

之
  • 「臣之壯也，猶不如人」——燭之武退秦師：主謂之間助詞，取消句子獨立性，無實義
  • 「聞之，欣然規往」——桃花源記：代詞，代指「桃花源這件事」
  • 「不知將軍寬之至此也」——語文延伸例句：代詞，代指人；另可比對「輟耕之壟上」（動詞，往、到，出自史傳文常見句型）
  • 「送杜少府之任蜀州」句型中「之」作動詞「往」解，可與代詞、助詞用法對照辨析
以
  • 「以光先帝遺德」——出師表：介詞，用來、藉以
  • 「作師說以貽之」——師說：連詞，表目的，來、以便
  • 「不以物喜，不以己悲」——岳陽樓記：介詞，因為
  • 「秦亦不以城予趙」句型中「以」作動詞「把、將」解，屬另一常考用法
而
  • 「侶魚蝦而友麋鹿」——赤壁賦：連詞，表並列，可不譯
  • 「青，取之於藍，而青於藍」——勸學：連詞，表轉折，卻、但是
  • 「吾嘗終日而思矣」——勸學：連詞，表修飾（連接狀語與動詞），可不譯
  • 「置之地，拔劍撞而破之」句型中「而」表承接，然後、接著，是第四種常考用法
其
  • 「必先苦其心志，勞其筋骨」句型中「其」作代詞「他的」解，屬最基本用法
  • 「其必曰『先天下之憂而憂』歟」——岳陽樓記：語氣副詞，表推測，大概、恐怕
  • 「其孰能譏之乎」句型中「其」表反詰語氣，難道，是另一種常考語氣副詞用法
  • 「郁離子曰：『其如是，豈不快哉』」——郁離子：代詞，指代前文所述之事
於
  • 「移其民於河東」句型中「於」表方向、地點，到、往
  • 「青，取之於藍，而青於藍」——勸學：前一「於」表來源（從），後一「於」表比較（比）——同句兩種用法對照，是學測極高頻考點
  • 「議法度而修之於朝廷」句型中「於」表處所，在

🔀特殊句法與倒裝

文言文為求語氣強調或音律和諧，常將現代語序中的成分前置或後置，還原為現代語序是學測文言文理解的重要能力：

句型類型原句（全文引用）出處還原現代語序
賓語前置「夫晉，何厭之有？」燭之武退秦師夫晉，有何厭？（「之」為提賓標誌，無義）
賓語前置「句讀之不知，惑之不解」師說不知句讀，不解惑
狀語（介詞結構）後置「刻唐賢今人詩賦於其上」岳陽樓記於其上刻唐賢今人詩賦
狀語後置「多會於此」蘭亭集序於此多會（眾人多聚會於此地）
省略句（省主語）「（漁人）便舍船，從口入」桃花源記漁人便捨棄船隻，從洞口進入
省略句（省介詞受詞）「林盡（於）水源」桃花源記桃花林在水源處到了盡頭
被動句「而君幸於趙王」句型（延伸例句，供對照）語文延伸補充「於」表被動，被趙王寵幸

上表倒數第二列之省略句、末列之被動句延伸例句用於補充句型概念對照，其餘均為古文30篇原文全文引用。

💡 辨識賓語前置的口訣

文言文中，當「疑問代詞（何、誰、孰等）」作賓語，或否定句中代詞作賓語時，賓語常會提到動詞之前，並可能加上「之」「是」等字作為提賓標誌（如「何厭之有」＝「有何厭」）。判讀時，先找出句中的動詞，再判斷動詞前的成分是否應該是動詞後的受詞，就能快速辨識倒裝現象。

🎨修辭手法舉隅

對偶

「白露橫江，水光接天」（赤壁賦）；「日出而林霏開，雲歸而巖穴暝」（醉翁亭記）——上下句字數相等、詞性相對，音節整齊而富音樂性。

排比

「東風不來，柳絮不飛」式的連續句型結構，亦見於出師表「親賢臣，遠小人，此先漢所以興隆也；親小人，遠賢臣，此後漢所以傾頹也」——三個以上結構相似的句子並列，加強語氣與說服力。

譬喻

「霪雨霏霏，連月不開；陰風怒號，濁浪排空」（岳陽樓記）以自然景象譬喻士人憂讒畏譏的心境；「青，取之於藍，而青於藍」（勸學）以染青之喻說明學習可超越本源。

引用

「其必曰『先天下之憂而憂，後天下之樂而樂』歟」（岳陽樓記）引用古仁人之言明志；「禮義廉恥，國之四維」（廉恥）引用五代史馮道傳論以立論根據。

摹寫（感官描寫）

「陰風怒號，濁浪排空」「薄暮冥冥，虎嘯猿啼」（岳陽樓記）以視覺、聽覺摹寫渲染登樓所見之蕭然景象，帶動讀者感官共鳴。

映襯（對比）

岳陽樓記以「霪雨霏霏」的悲景與「春和景明」的樂景前後對照，襯托出「不以物喜，不以己悲」的古仁人之心更為可貴。

文化基本教材：〈大同與小康〉重點段落全文引用

📌 節錄說明

〈大同與小康〉選自《禮記．禮運》，全篇連同前後文較長，此處依循「過長則節錄重點段落」原則，僅完整引用最核心、也是學測最常考的「大同」段落全文，供本週複習核對。

大道之行也，天下為公。選賢與能，講信修睦。故人不獨親其親，不獨子其子，使老有所終，壯有所用，幼有所長，矜寡孤獨廢疾者皆有所養。男有分，女有歸。貨惡其棄於地也，不必藏於己；力惡其不出於身也，不必為己。是故謀閉而不興，盜竊亂賊而不作，故外戶而不閉，是謂大同。

在大道施行的時代，天下是公眾共有的。人們推舉德行才能兼備的人來治理天下，彼此講求誠信、修習和睦。因此人們不只親愛自己的親人，不只疼愛自己的子女，使老年人都能安享天年，壯年人都能貢獻所長，幼年人都能順利成長，鰥寡孤獨與殘疾之人都能得到供養。男子有其應盡的職分，女子有其應歸的夫家。財貨，人們厭惡它被棄置在地上無用，卻不一定要據為己有；力氣，人們厭惡它不從自己身上使出，卻不一定只為自己謀利。因此，陰謀詭計因此不會興起，盜竊、作亂、害人的事也不會發生，所以家家戶戶大門都不用關閉，這就叫做「大同」之世。

📝重點整理

✅ 國寫感性題 重點速記
  • 感性題測情感體察與細節經營，非邏輯論證
  • 評分四規準：取材真摯度、意象經營、結構層次、語言文采
  • 寫作結構：畫面切入—細節鋪陳—轉念體悟—收束呼應
  • 最忌情感空喊口號，缺乏具體細節支撐
✅ 古文語文知識 重點速記
  • 通同字：共＝供、說＝悅、要＝邀、不＝否、有＝又、闕＝缺
  • 一字多義高頻字：之、以、而、其、於，須依上下文判斷詞性與意義
  • 特殊句法：賓語前置（何厭之有）、狀語後置（刻詩賦於其上）
  • 修辭手法：對偶、排比、譬喻、引用、摹寫、映襯，皆有古文30篇實例可查
⭐ 學測作答策略
  • 國寫感性題落筆前，先花 3–5 分鐘構思大綱，確定「具體物件或畫面」與「情感轉折點」，避免邊寫邊想導致結構鬆散
  • 語文知識選擇題遇到不熟悉的字詞，可先回想是否出現在古文30篇中曾學過的句子，再依上下文判斷詞性與意義
  • 一字多義題型的解題關鍵在於「先判斷詞性（代詞／介詞／連詞／語氣詞），再determine意義」，而非死記單一意義
  • 特殊句法題型可用「先找動詞，再判斷動詞前後成分」的方法快速還原現代語序

作答說明

以下共 8 題單選題，每題閱讀後先自行作答，再點開「查看解答」確認。本測驗涵蓋國寫感性題與古文語文知識整理兩大範疇，建議合上講義獨立作答。

1下列關於國寫「感性題」的敘述，何者正確？
  1. 感性題的評分重點在於情感是否濃烈誇張，情緒詞彙用得越多越好
  2. 感性題應著重具體細節與意象經營，讓抽象情感透過可感的畫面呈現
  3. 感性題與知性題完全相同，只是題目名稱不同
  4. 感性題不需要篇章結構，只要情感真實即可
查看解答與解析

正確答案：B

感性題重視具體細節與意象經營，避免空泛喊出情緒詞彙；仍需要有清楚的起承轉合結構，與知性題著重邏輯論證的方向明顯不同。

2「夫晉，何厭之有？」一句中，「之」字的文法作用為何？
  1. 代詞，代指前文所述之事
  2. 提賓標誌，將賓語「何厭」提到動詞「有」之前，本句應理解為「有何厭」
  3. 連詞，表示轉折
  4. 語氣助詞，用於句末加強語氣
查看解答與解析

正確答案：B

本句為賓語前置句型，「之」為提賓標誌本身無實義，正常語序應為「有何厭」，意即「還有什麼可以滿足的呢」，出自〈燭之武退秦師〉。

3「青，取之於藍，而青於藍」句中，兩個「於」字的意義，下列敘述何者正確？
  1. 兩個「於」字意義相同，皆表示地點
  2. 前一個「於」表比較（比），後一個「於」表來源（從）
  3. 前一個「於」表來源（從），後一個「於」表比較（比）
  4. 兩個「於」字皆為語氣助詞，無實質意義
查看解答與解析

正確答案：C

「取之於藍」的「於」表來源，意為「從藍草中提取」；「青於藍」的「於」表比較，意為「比藍草更青」。同句中同一字有兩種不同意義，是學測極高頻的一字多義考點，出自〈勸學〉。

4「秦伯說，與鄭人盟」句中，「說」字應通何字？意義為何？
  1. 通「悅」，高興、喜悅
  2. 通「說」，勸說
  3. 通「脫」，脫離
  4. 通「悅」，但意義為「說話」
查看解答與解析

正確答案：A

此為通假字，「說」通「悅」，讀作「ㄩㄝˋ」，意為高興、喜悅，出自〈燭之武退秦師〉，描述秦伯聽了燭之武的說詞後感到高興，於是與鄭人結盟。

5下列文句，何者運用了「對偶」修辭手法？
  1. 「便要還家，設酒殺雞作食」
  2. 「白露橫江，水光接天」
  3. 「聞之，欣然規往」
  4. 「爾來二十有一年矣」
查看解答與解析

正確答案：B

「白露橫江，水光接天」出自〈赤壁賦〉，上下句字數相等（「白露」對「水光」、「橫江」對「接天」），詞性相對，是典型的對偶修辭。

6依本週寫作大綱示範，感性題「那件小事物」一題，最適當的開頭方式為何？
  1. 直接寫「我有一件對我很重要的東西，那就是一支鋼筆」
  2. 先描繪一個具體的當下畫面（如翻找抽屜時觸碰到那支筆），再自然帶出回憶
  3. 先大篇幅論述「物件承載情感」這個抽象道理
  4. 直接列點說明這件物件的三個優點
查看解答與解析

正確答案：B

感性題宜以具體畫面切入，透過細節自然帶出回憶與情感，避免像知性題一樣直接以抽象陳述或條列式開頭，才能營造感染力。

7下列作者與其稱號或文學史地位的配對，何者錯誤？
  1. 韓愈——唐宋古文八大家之首
  2. 范仲淹——「先天下之憂而憂，後天下之樂而樂」名句作者
  3. 黃宗羲——《明夷待訪錄》作者，明末清初三大儒之一
  4. 郁永河——北宋政治家，著有《岳陽樓記》
查看解答與解析

正確答案：D

《岳陽樓記》作者為北宋范仲淹，非郁永河；郁永河是清代來台採硫的文人，著有《裨海紀遊》，是現存最早詳細記錄台灣風土的遊記文獻。

8「刻唐賢今人詩賦於其上」一句，屬於下列何種文言特殊句法？還原現代語序後應如何理解？
  1. 賓語前置，還原後為「於其上刻唐賢今人詩賦」
  2. 狀語（介詞結構）後置，還原後為「於其上刻唐賢今人詩賦」
  3. 被動句，還原後為「詩賦被刻於其上」
  4. 判斷句，還原後為「其上是唐賢今人詩賦」
查看解答與解析

正確答案：B

「於其上」是介詞結構作狀語，文言文中常將此類狀語移至句末，還原現代語序時應提到動詞之前：「於其上刻唐賢今人詩賦」，出自〈岳陽樓記〉。
