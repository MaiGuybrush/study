📚 學習總覽

上週學會了直角三角形中的三角比（僅限 0°~90° 的銳角）。本週要把三角比的定義推廣到任意角度——這就是「廣義角」，並引入弧度制作為角度的另一種度量方式。有了廣義角的定義後，三角比就不再侷限於直角三角形，而可以應用到任意三角形：正弦定理與餘弦定理正是處理一般三角形邊角關係的核心工具，也是三角學單元中學測考最頻繁、綜合難度最高的部分之一。

本週學習目標
  • 理解廣義角的定義（旋轉角、始邊、終邊）與正負角、象限角的判斷
  • 熟練弧度制與角度制的互換，理解弧度制的本質（弧長 ÷ 半徑）
  • 能用單位圓定義任意角 \(\theta\) 的六種三角比，並判斷各象限的正負號（ASTC 法則）
  • 熟記特別角（0°, 30°, 45°, 60°, 90°, 180°, 270°, 360° 及其弧度）的三角比數值
  • 能利用誘導公式將任意角三角比化為銳角三角比求值
  • 能運用正弦定理與餘弦定理求解一般三角形（非直角三角形）的邊角
  • 能用三角形面積公式（\(\frac12 ab\sin C\)）與海龍公式求三角形面積

第二冊 第二章｜廣義角與三角比性質
弧度制・單位圓定義・象限正負・誘導公式

廣義角的定義

定義：廣義角（Generalized Angle）

將角視為一條射線繞頂點旋轉所形成，固定不動的射線稱為始邊，旋轉後的射線稱為終邊。逆時針旋轉為正角，順時針旋轉為負角。旋轉角度可以超過 360°，也可以是負值，這樣定義出來的角就是廣義角。

  • 標準位置角：始邊置於 x 軸正向、頂點置於原點的角
  • 象限角：終邊落在第幾象限，就稱為第幾象限角；若終邊剛好落在座標軸上，稱為象限界角（如 90°, 180°, 270°, 360°）
  • 同界角（共終邊角）：終邊相同的角，彼此相差 360° 的整數倍，即 \(\theta + k \times 360°\)（\(k\) 為整數）都與 \(\theta\) 同界
例1：求與 400° 同界（終邊相同）的角中，介於 −360° 到 0° 之間的角。
同界角公式：\(\theta = 400° + k \times 360°\)（\(k\) 為整數）
取 \(k=-1\)：\(400° - 360° = 40°\)（不在範圍內）
取 \(k=-2\)：\(400° - 720° = -320°\)（在 −360°~0° 之間）
答：−320°

弧度制（Radian Measure）

定義：弧度（radian, rad）

在圓中，若弧長恰等於半徑長，則該弧所對的圓心角稱為 1 弧度。一般地，圓心角 \(\theta\)（弧度）\(=\dfrac{\text{弧長}}{\text{半徑}} = \dfrac{s}{r}\)。弧度是「比值」，本質上沒有單位，但習慣上仍標記為 rad（常省略不寫）。

度與弧度互換
\[180° = \pi \text{ (rad)} \quad\Longrightarrow\quad 1° = \frac{\pi}{180}\text{ rad}, \qquad 1\text{ rad} = \frac{180°}{\pi}\]
常用角度與弧度對照表
度0°30°45°60°90°180°270°360°
弧度\(0\)\(\dfrac{\pi}{6}\)\(\dfrac{\pi}{4}\)\(\dfrac{\pi}{3}\)\(\dfrac{\pi}{2}\)\(\pi\)\(\dfrac{3\pi}{2}\)\(2\pi\)
換算技巧

度數換弧度：乘以 \(\dfrac{\pi}{180}\)；弧度換度數：乘以 \(\dfrac{180}{\pi}\)。建議直接記住上表中八個常用角，考試時能快速反應，不需每次重新計算。

例2：(a) 將 210° 換算為弧度。(b) 將 \(\dfrac{5\pi}{4}\) 弧度換算為度。
(a) \(210° \times \dfrac{\pi}{180} = \dfrac{210\pi}{180} = \dfrac{7\pi}{6}\)
(b) \(\dfrac{5\pi}{4} \times \dfrac{180}{\pi} = \dfrac{5 \times 180}{4} = 225°\)
答：(a) \(\dfrac{7\pi}{6}\)　(b) 225°
扇形弧長與面積公式（弧度制下最簡潔）
\[s = r\theta, \qquad A = \frac{1}{2}r^2\theta\]

（\(\theta\) 須以弧度為單位；此為弧度制的最大優點——公式不含 180 或 \(\pi\) 的繁瑣係數）

單位圓上的三角函數定義

定義：任意角三角比（單位圓定義）

設 \(\theta\) 為標準位置角，終邊與單位圓（圓心在原點、半徑為 1 的圓）的交點為 \(P(x, y)\)，則定義：

\[\sin\theta = y, \qquad \cos\theta = x, \qquad \tan\theta = \frac{y}{x}\ (x \neq 0)\]

更一般地，若終邊上任一點為 \(P(x,y)\)，\(r=\sqrt{x^2+y^2}\)（不限單位圓），則：

\[\sin\theta=\frac{y}{r},\quad \cos\theta=\frac{x}{r},\quad \tan\theta=\frac{y}{x}\ (x\neq0)\]
與直角三角形定義的銜接

當 \(\theta\) 為銳角時，單位圓定義與上週的「對邊/斜邊」定義完全一致（此時 \(r=1\) 即斜邊，\(x, y\) 分別對應鄰邊、對邊的帶號長度）。單位圓定義的優勢在於能自然推廣到鈍角、負角、大於 360° 的角，因為 \(x, y\) 可以是負值。

三角函數的正負與象限（ASTC 法則）

由於 \(\sin\theta=y/r\)、\(\cos\theta=x/r\)（\(r>0\) 恆成立），三角比的正負完全由終邊所在象限的 \(x, y\) 正負決定。

第一象限（All）

\(x>0, y>0\)：\(\sin\theta, \cos\theta, \tan\theta\) 全部為正

第二象限（Sin）

\(x<0, y>0\)：只有 \(\sin\theta\) 為正（\(\cos,\tan\) 為負）

第三象限（Tan）

\(x<0, y<0\)：只有 \(\tan\theta\) 為正（\(\sin,\cos\) 為負）

第四象限（Cos）

\(x>0, y<0\)：只有 \(\cos\theta\) 為正（\(\sin,\tan\) 為負）

記憶口訣：All Students Take Calculus（ASTC）

從第一象限開始逆時針：A(全正) → S(正弦正) → T(正切正) → C(餘弦正)。中文口訣可記「一全正、二正弦、三正切、四餘弦」。

例3：已知 \(\theta\) 為第三象限角，且 \(\sin\theta = -\dfrac{5}{13}\)，求 \(\cos\theta\) 與 \(\tan\theta\)。
設終邊上一點 \(P(x,y)\)，\(r=13\)，\(y=-5\)（因 \(\sin\theta=y/r=-5/13\)）
由 \(x^2+y^2=r^2\)：\(x^2 = 13^2-5^2=169-25=144 \Rightarrow x=\pm12\)
\(\theta\) 為第三象限角，\(x<0\)，故 \(x=-12\)
\(\cos\theta = \dfrac{x}{r}=\dfrac{-12}{13}\)，\(\tan\theta=\dfrac{y}{x}=\dfrac{-5}{-12}=\dfrac{5}{12}\)
答：\(\cos\theta=-\dfrac{12}{13}\)，\(\tan\theta=\dfrac{5}{12}\)（驗證：第三象限 tan 為正，符合 ASTC）

特別角三角比（含 0°、90°、180°、270°、360°）

象限界角三角比對照表
\(\theta\)0（0°）\(\pi/2\)（90°）\(\pi\)（180°）\(3\pi/2\)（270°）\(2\pi\)（360°）
\(\sin\theta\)010−10
\(\cos\theta\)10−101
\(\tan\theta\)0未定義0未定義0
推導方式（不需死背）

把單位圓上對應點 \((\cos\theta,\sin\theta)\) 直接畫出來：0° 為 \((1,0)\)、90° 為 \((0,1)\)、180° 為 \((-1,0)\)、270° 為 \((0,-1)\)、360° 又回到 \((1,0)\)。\(\tan\theta\) 在 \(x=0\) 時（即 90°、270°）分母為零，故未定義。

基本三角恆等式（推廣至任意角）

上週學過的三個基本恆等式（畢氏恆等式、商數關係、倒數關係）在單位圓定義下，對任意角 \(\theta\)（使函數有定義處）依然成立：

\[\sin^2\theta+\cos^2\theta=1, \qquad \tan\theta=\frac{\sin\theta}{\cos\theta}, \qquad \sec\theta=\frac1{\cos\theta},\ \csc\theta=\frac1{\sin\theta},\ \cot\theta=\frac1{\tan\theta}\]
例4：已知 \(\theta\) 為第二象限角，且 \(\cos\theta=-\dfrac35\)，求 \(\sin\theta\)。
\(\sin^2\theta = 1-\cos^2\theta = 1-\dfrac{9}{25}=\dfrac{16}{25}\)
第二象限 \(\sin\theta>0\)（依 ASTC），故 \(\sin\theta=\dfrac45\)
答：\(\sin\theta=\dfrac45\)

誘導公式（化為銳角三角比）

誘導公式（reduction formula）的用途是：把任意角的三角比，轉換成 0°~90° 銳角的三角比，方便查表或代入特殊角數值。核心原則只有兩步：①先定正負號（用 ASTC 判斷原角所在象限）②再看角度是 \(90°\pm\theta\)、\(180°\pm\theta\) 還是 \(360°-\theta\) 型，決定函數名稱是否互換。

常用誘導公式（\(\theta\) 為銳角）
類型\(\sin\)\(\cos\)\(\tan\)函數名稱
\(180°-\theta\)\(\sin\theta\)\(-\cos\theta\)\(-\tan\theta\)不變
\(180°+\theta\)\(-\sin\theta\)\(-\cos\theta\)\(\tan\theta\)不變
\(360°-\theta\)（即 \(-\theta\)）\(-\sin\theta\)\(\cos\theta\)\(-\tan\theta\)不變
\(90°-\theta\)\(\cos\theta\)\(\sin\theta\)\(\cot\theta\)互換
\(90°+\theta\)\(\cos\theta\)\(-\sin\theta\)\(-\cot\theta\)互換
口訣：「奇變偶不變，符號看象限」

將角度寫成 \(k\times90°\pm\theta\) 的形式：若 \(k\) 為奇數（如 90°、270°），\(\sin\) 與 \(\cos\) 互換（函數名稱「變」）；若 \(k\) 為偶數（如 180°、360°），函數名稱不變。正負號則把 \(\theta\) 當銳角，看原角落在哪個象限，用 ASTC 判斷。

例5：求 \(\sin150°\) 與 \(\cos210°\) 之值。
\(150°=180°-30°\)，屬「\(180°-\theta\)」型（偶數個 90°，函數不變）；150° 在第二象限，\(\sin\) 為正
\(\sin150° = \sin30° = \dfrac12\)
\(210°=180°+30°\)，屬「\(180°+\theta\)」型（函數不變）；210° 在第三象限，\(\cos\) 為負
\(\cos210° = -\cos30° = -\dfrac{\sqrt3}{2}\)
答：\(\sin150°=\dfrac12\)，\(\cos210°=-\dfrac{\sqrt3}{2}\)
例6：求 \(\tan(-45°)\) 與 \(\sin300°\) 之值。
\(\tan(-45°)\)：屬 \(360°-\theta\) 型（即負角），\(-45°\) 相當於第四象限，\(\tan\) 為負；\(\tan(-45°)=-\tan45°=-1\)
\(300°=360°-60°\)，第四象限，\(\sin\) 為負；\(\sin300°=-\sin60°=-\dfrac{\sqrt3}{2}\)
答：\(\tan(-45°)=-1\)，\(\sin300°=-\dfrac{\sqrt3}{2}\)
正弦定理與餘弦定理
一般三角形（非直角）的邊角關係・三角形面積公式

正弦定理（Law of Sines）

設 \(\triangle ABC\) 三邊 \(a, b, c\) 分別對角 \(A, B, C\)，外接圓半徑為 \(R\)：

正弦定理
\[\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R\]
使用時機
  • AAS / ASA（已知兩角一邊）：求其餘邊
  • SSA（已知兩邊及其中一邊的對角）：求另一邊的對角（注意可能有「兩解、一解、無解」的模稜兩可情形）
  • 求三角形外接圓半徑 \(R\)
例7：\(\triangle ABC\) 中，\(A=45°\)，\(B=60°\)，\(a=8\)。求 \(b\)。
由正弦定理：\(\dfrac{a}{\sin A}=\dfrac{b}{\sin B} \Rightarrow \dfrac{8}{\sin45°}=\dfrac{b}{\sin60°}\)
\(b = \dfrac{8\sin60°}{\sin45°} = \dfrac{8\times\frac{\sqrt3}{2}}{\frac{\sqrt2}{2}} = \dfrac{4\sqrt3}{\frac{\sqrt2}{2}} = \dfrac{8\sqrt3}{\sqrt2}=4\sqrt6\)
答：\(b=4\sqrt6\)
SSA 模稜兩可情形（重要！）

已知兩邊及非夾角（SSA）時，可能對應兩個、一個或零個三角形，需檢查求出的角是否讓內角和超過 180°，或需分別討論銳角、鈍角兩種可能解。這是學測與課堂上常出的陷阱題型。

餘弦定理（Law of Cosines）

餘弦定理（三個等價式）
\[a^2 = b^2+c^2-2bc\cos A\] \[b^2 = a^2+c^2-2ac\cos B\] \[c^2 = a^2+b^2-2ab\cos C\]
推導概念

餘弦定理可視為畢氏定理的推廣：當 \(C=90°\) 時，\(\cos C=0\)，\(c^2=a^2+b^2-2ab\times0=a^2+b^2\)，正是畢氏定理。因此餘弦定理在直角三角形會自動退化為畢氏定理。

使用時機
  • SAS（已知兩邊及夾角）：求第三邊
  • SSS（已知三邊）：求任一角（把公式反解 \(\cos\theta\)）
求角公式（由 SSS 反解）
\[\cos A = \frac{b^2+c^2-a^2}{2bc}, \qquad \cos B = \frac{a^2+c^2-b^2}{2ac}, \qquad \cos C=\frac{a^2+b^2-c^2}{2ab}\]
例8：\(\triangle ABC\) 中，\(b=7\)，\(c=5\)，\(A=60°\)。求 \(a\)。
\(a^2 = b^2+c^2-2bc\cos A = 7^2+5^2-2\times7\times5\times\cos60°\)
\(=49+25-70\times\dfrac12 = 74-35=39\)
答：\(a=\sqrt{39}\)
例9：\(\triangle ABC\) 中，\(a=5\)，\(b=6\)，\(c=7\)。求 \(\cos C\)（\(C\) 為 \(c\) 的對角）並判斷 \(C\) 為銳角或鈍角。
\(\cos C = \dfrac{a^2+b^2-c^2}{2ab} = \dfrac{25+36-49}{2\times5\times6}=\dfrac{12}{60}=\dfrac15\)
答：\(\cos C=\dfrac15 > 0\)，故 \(C\) 為銳角（\(\cos\) 為正對應 0°~90°）
判斷三角形形狀的技巧

由 \(\cos\theta\) 的正負可直接判斷該角銳鈍：\(\cos\theta>0\) → 銳角；\(\cos\theta=0\) → 直角；\(\cos\theta<0\) → 鈍角。只需檢查最大邊所對的角即可判斷整個三角形是銳角、直角還是鈍角三角形。

如何選用正弦定理或餘弦定理？

選用判斷表
已知條件代號建議使用
兩角一邊AAS / ASA正弦定理
兩邊及非夾角SSA正弦定理（注意模稜兩可）
兩邊及夾角SAS餘弦定理
三邊SSS餘弦定理
記憶技巧

正弦定理處理「角對角」型態的關係（一邊配它的對角）；餘弦定理處理「夾角」型態的關係（兩邊夾一個角，或已知三邊求任一角）。若已知條件中沒有「一組邊角對應好的完整比例」，通常就是餘弦定理的天下。

三角形面積公式與海龍公式

面積公式一：兩邊夾角型（SAS 型）
\[\text{面積} = \frac12 ab\sin C = \frac12 bc\sin A = \frac12 ac\sin B\]

（任取兩邊，乘上其夾角的正弦，再除以 2）

面積公式二：海龍公式（Heron's Formula，SSS 型）
\[s = \frac{a+b+c}{2}\ (\text{半周長}), \qquad \text{面積} = \sqrt{s(s-a)(s-b)(s-c)}\]
例10：\(\triangle ABC\) 中，\(a=6\)，\(b=8\)，\(C=30°\)。求面積。
面積 \(=\dfrac12 ab\sin C = \dfrac12 \times6\times8\times\sin30° = 24\times\dfrac12=12\)
答：面積為 12
例11：三邊長為 \(5, 6, 7\) 的三角形，求其面積（海龍公式）。
半周長：\(s=\dfrac{5+6+7}{2}=9\)
面積 \(=\sqrt{9(9-5)(9-6)(9-7)}=\sqrt{9\times4\times3\times2}=\sqrt{216}\)
\(\sqrt{216}=\sqrt{36\times6}=6\sqrt6\)
答：面積為 \(6\sqrt6\)
🔗 連結：與正弦定理的關係

面積公式 \(\frac12 ab\sin C\) 搭配正弦定理 \(\dfrac{c}{\sin C}=2R\)，可推導出「面積 \(=\dfrac{abc}{4R}\)」（\(R\) 為外接圓半徑），是進階題型中常出現的綜合公式，可視個人程度延伸學習。

⚠️ 常見錯誤

錯誤1：弧度與角度混用，忘記轉換

計算機或公式中若未統一單位，\(\sin(3)\) 這種輸入是把 3 當成「3 弧度」而非「3 度」，兩者數值天差地遠。考試中若題目給的是弧度（含 \(\pi\)），計算全程都要用弧度，不可中途換回度數又忘記轉換。

錯誤2：誘導公式的正負號判斷錯誤

誘導公式最容易出錯的地方不是「函數名稱變不變」，而是正負號。務必先想清楚原角落在哪個象限（把 \(\theta\) 當成銳角去畫圖），再用 ASTC 判斷正負，不要憑記憶硬套公式表。

錯誤3：SSA 情形直接套正弦定理，忽略模稜兩可

已知兩邊一夾其中一邊的對角（SSA）時，求出的角可能有兩個解（一銳角一鈍角，因為 \(\sin\theta=\sin(180°-\theta)\)）。若忽略這點，容易漏解或誤解。務必檢查兩個角是否都能使三角形內角和為 180°。

錯誤4：餘弦定理公式中的邊角對應搞混

\(a^2=b^2+c^2-2bc\cos A\) 中，\(a\) 必須是 \(A\) 的對邊，等號右側是「另外兩邊」及它們的夾角 \(A\)。很多學生會把邊角對應弄反，建議套用前先明確標出三角形的邊角對應關係。

錯誤5：海龍公式的 s 誤用為周長而非半周長

\(s\) 是半周長 \(\dfrac{a+b+c}{2}\)，而非三邊和本身。代錯會導致面積公式整個算錯，務必先算出 \(s\) 再代入。

🎯 學測考點提醒

歷屆學測命題趨勢
  • 正弦定理、餘弦定理是學測數學A科最常考的三角學主題之一，常以「測量問題」（山高、船位、兩地距離）包裝，需要學生自行判斷該用哪個定理
  • 誘導公式常與「化簡三角函數表達式」結合，考驗學生對 ASTC 與奇變偶不變口訣的熟練度
  • 弧度制常搭配扇形弧長、面積出題，或與後續的三角函數圖形（第三冊A）銜接
  • 海龍公式與「三角形面積 \(\frac12ab\sin C\)」常被要求交叉驗證，或反過來由面積求某邊、某角
  • SSA 模稜兩可情形是進階選擇題常見陷阱，務必練習判斷「兩解、一解、無解」三種情況
解題策略提醒

遇到一般三角形問題，第一步永遠是畫圖並標出已知的邊角，接著對照「選用判斷表」（AAS/ASA→正弦；SAS/SSS→餘弦），選定策略後再代公式，可大幅降低套錯公式的機率。

✍ 自我檢測（共 10 題）

作答說明

以下 10 題涵蓋本週廣義角、正弦定理與餘弦定理核心概念，建議先自行作答再對照詳解。難度以 易 中 難 標示。

1將 \(135°\) 換算為弧度。易
  1. \(\dfrac{\pi}{4}\)
  2. \(\dfrac{3\pi}{4}\)
  3. \(\dfrac{5\pi}{4}\)
  4. \(\dfrac{3\pi}{2}\)
查看解析
答案：B
\(135° \times \dfrac{\pi}{180} = \dfrac{135\pi}{180}=\dfrac{3\pi}{4}\)
2\(\theta\) 為第三象限角，下列敘述何者正確？易
  1. \(\sin\theta>0,\cos\theta>0\)
  2. \(\sin\theta>0,\cos\theta<0\)
  3. \(\sin\theta<0,\cos\theta<0\)
  4. \(\sin\theta<0,\cos\theta>0\)
查看解析
答案：C
第三象限依 ASTC 法則，只有 \(\tan\theta\) 為正，\(\sin\theta,\cos\theta\) 皆為負。
3求 \(\cos120°\) 之值。易
  1. \(\dfrac12\)
  2. \(-\dfrac12\)
  3. \(\dfrac{\sqrt3}{2}\)
  4. \(-\dfrac{\sqrt3}{2}\)
查看解析
答案：B
\(120°=180°-60°\)，第二象限 \(\cos\) 為負：\(\cos120° = -\cos60° = -\dfrac12\)
4已知銳角 \(\theta\) 之終邊上一點為 \((3,4)\)（未在單位圓上），求 \(\sin\theta\)。中
  1. \(\dfrac35\)
  2. \(\dfrac45\)
  3. \(\dfrac34\)
  4. \(\dfrac43\)
查看解析
答案：B
\(r=\sqrt{3^2+4^2}=5\)，\(\sin\theta=\dfrac{y}{r}=\dfrac45\)
5\(\triangle ABC\) 中，\(A=30°\)，\(B=45°\)，\(b=10\)。求 \(a\)。中
  1. \(5\sqrt2\)
  2. \(5\)
  3. \(10\sqrt2\)
  4. \(5\sqrt3\)
查看解析
答案：A
由正弦定理：\(\dfrac{a}{\sin A}=\dfrac{b}{\sin B} \Rightarrow \dfrac{a}{\sin30°}=\dfrac{10}{\sin45°}\)
\(a = \dfrac{10\sin30°}{\sin45°} = \dfrac{10\times\frac12}{\frac{\sqrt2}{2}} = \dfrac{5}{\frac{\sqrt2}{2}}=\dfrac{10}{\sqrt2}=5\sqrt2\)
此類題型的標準流程：已知兩角一邊（AAS/ASA）時，若第三角未給，先用內角和 180° 求出第三角，再套正弦定理求邊。
6\(\triangle ABC\) 中，\(b=4\)，\(c=6\)，\(A=60°\)。求 \(a\)。中
  1. \(\sqrt{28}=2\sqrt7\)
  2. \(\sqrt{52}\)
  3. \(2\)
  4. \(\sqrt{40}\)
查看解析
答案：A
\(a^2=4^2+6^2-2\times4\times6\times\cos60°=16+36-48\times\dfrac12=52-24=28\)
\(a=\sqrt{28}=2\sqrt7\)
7\(\triangle ABC\) 中，\(a=3\)，\(b=4\)，\(c=6\)。判斷此三角形形狀（求最大角 \(C\) 之 \(\cos C\) 並判斷銳鈍）。難
  1. \(\cos C>0\)，銳角三角形
  2. \(\cos C=0\)，直角三角形
  3. \(\cos C<0\)，鈍角三角形
  4. 無法判斷
查看解析
答案：C
最大邊為 \(c=6\)，其對角 \(C\) 必為最大角。
\(\cos C = \dfrac{a^2+b^2-c^2}{2ab} = \dfrac{9+16-36}{2\times3\times4}=\dfrac{-11}{24}<0\)
\(\cos C<0\)，故 \(C\) 為鈍角，此三角形為鈍角三角形。
8\(\triangle ABC\) 中，\(a=8\)，\(b=5\)，\(C=60°\)。求三角形面積。中
  1. \(10\)
  2. \(20\)
  3. \(10\sqrt3\)
  4. \(20\sqrt3\)
查看解析
答案：C
面積 \(=\dfrac12 ab\sin C = \dfrac12\times8\times5\times\sin60° = 20\times\dfrac{\sqrt3}{2}=10\sqrt3\)
9三邊長為 \(4,13,15\) 的三角形，求其面積（海龍公式）。難
  1. \(24\)
  2. \(26\)
  3. \(30\)
  4. \(36\)
查看解析
答案：A
\(s=\dfrac{4+13+15}{2}=16\)
面積 \(=\sqrt{16(16-4)(16-13)(16-15)}=\sqrt{16\times12\times3\times1}=\sqrt{576}=24\)
10甲、乙兩船同時從港口 \(O\) 出發，甲船以方位角（正北為 0°，順時針量）\(N30°E\) 方向航行 40 浬，乙船以 \(N90°E\)（即正東）方向航行 30 浬。兩船之間的夾角為 60°，求此時兩船的距離。難
  1. \(10\sqrt7\) 浬
  2. \(10\sqrt{13}\) 浬
  3. \(35\) 浬
  4. \(50\) 浬
查看解析
答案：B
設兩船距離為 \(d\)，港口 \(O\) 與甲、乙兩船構成三角形，\(O\) 處夾角為 60°，兩邊為 40、30（SAS 型）。
由餘弦定理：\(d^2 = 40^2+30^2-2\times40\times30\times\cos60°\)
\(=1600+900-2400\times\dfrac12 = 2500-1200=1300\)
\(d=\sqrt{1300}=\sqrt{100\times13}=10\sqrt{13}\) 浬

  • 正弦/餘弦定理選用猶豫：牢記判斷表，看到「角對邊完整比例」用正弦，看到「夾角」或「三邊」用餘弦
